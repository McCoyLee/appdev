# 定时任务

每天定时跑一个 Python 脚本，结果发到你的邮箱。

## 怎么用

1. 在客户端密码本添加 `SMTP_USER`、`SMTP_PASS`（QQ 邮箱开 SMTP 授权码教程：[官方文档](https://service.mail.qq.com/detail/0/75)）
2. 对 AI 说想做什么，比如：
   - "每天早上抓豆瓣热门电影前 10 名"
   - "每周一统计本仓库上周提交，发给我"
   - "每小时检测某网页是否更新"
3. AI 改 `src/job.py` 里的 `do_job()`，跑 CI 验证
4. 你点"就这版"采纳 → 第二天自动跑
